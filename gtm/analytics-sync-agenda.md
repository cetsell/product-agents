# Analytics Sync — [Day]

Standing agenda for the weekly GTM analytics sync.

## Agenda

1. **Metrics review** (10 min)
   - Top-line KPIs: traffic, signups, conversion to paid, MRR
   - Week-over-week changes
   - Any anomalies or red flags

2. **Attribution check** (10 min)
   - Campaign-level performance
   - Source/medium breakdown
   - Attribution tool status and data gaps

3. **Funnel health** (10 min)
   - Where are users dropping off?
   - Any data quality issues? (see `product/analytics/data-quality-log.md`)

4. **Action items** (5 min)
   - What needs fixing before next week?
   - Any experiments to launch or kill?

## Participants

- [Analytics owner] — presents metrics
- [GTM/Ops] — campaign context
- [PM] — product context
- [Acquisition] — paid channel context
