# New Member Checklist

First-week essentials for joining the team.

## Day 1: Access & Accounts

- [ ] Slack workspace access
- [ ] Linear workspace access (check `team/roster.md` for your team)
- [ ] Google Workspace (Drive, Docs, Calendar)
- [ ] Notion wiki access
- [ ] GitHub org access
- [ ] BigQuery access (if analytics/data role)
- [ ] Analytics tool access (if analytics/data role)

## Day 1-2: Context

- [ ] Read `team/roster.md` — know who's who
- [ ] Read `team/cadence.md` — know the weekly schedule
- [ ] Read `product/roadmap/current-bet.md` — know the current priority
- [ ] Read the latest `team/weekly-updates/` email — know what shipped recently
- [ ] Browse your team's Linear project — know what's in flight

## Day 2-3: Tools

- [ ] Set up development environment (see `tool-setup.md`)
- [ ] Install Claude Code (if using AI tools)
- [ ] Clone this repo (`team-os`) for shared context

## Day 3-5: People

- [ ] 1:1 with your team lead
- [ ] 1:1 with the PM (product context)
- [ ] Attend your first standup/kickoff
- [ ] Ask questions in Slack — no question is too small
