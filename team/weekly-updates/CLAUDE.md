# Weekly Updates

Weekly cadence notes and team update emails, written by `/cadence` and `/sprint-health`. One file per note, dated.

## Naming Convention

`YYYY-MM-DD-{mode}.md` — e.g. `2026-10-12-kickoff.md`, `2026-10-16-friday.md`, `2026-10-16-update.md`, `2026-10-12-sprint-health.md`

## Template

Use `templates/weekly-update.md` for the format.
