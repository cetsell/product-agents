# Team Cadence

Actual weekly schedule for Engineering and GTM teams.

## Engineering

| Day | Ritual | Notes |
|-----|--------|-------|
| Monday | Sprint kickoff | Review priorities, assign work for the week |
| Tuesday | Standup | |
| Wednesday | Eng office hours | Open troubleshooting, knowledge sharing |
| Wednesday | Cross-team sync | Bi-weekly — Eng + GTM alignment |
| Thursday | Standup | |
| Friday | Demo | Show what shipped |
| Friday | Sprint planning | Plan next sprint |
| Monthly | Retro | What went well, what didn't, action items |

## GTM

| Day | Ritual | Notes |
|-----|--------|-------|
| Monday | Sprint kickoff | Campaign priorities, blockers |
| Wednesday | Cross-team sync | Bi-weekly — GTM + Eng alignment |
| Thursday | Analytics sync | Review metrics, attribution, funnel health |
| Friday | Demo | Campaign results, creative reviews |
| Friday | GTM demo | GTM-specific showcase |
