# Customer Insights

Lightweight captures from customer calls, support interactions, and user research sessions.

## What's Here

One file per session or theme. Each file covers: source, key quotes, insight category, and action taken.

## Naming

`YYYY-MM-DD-[source]-[topic].md` — e.g., `2026-04-21-support-onboarding.md`

## When to Read

- Before designing a new experiment (what do users actually say?)
- Before writing a spec (what pain has been observed directly?)
- During monthly retros (what patterns emerged this month?)

## Template

Use `template.md` in this folder.

## Categories

- **onboarding** — friction in first session, drop-off points
- **content** — image/video requests, quality feedback, generation UX
- **voice** — call experience, character voice, billboard-driven users
- **pricing** — willingness to pay, objections, token confusion
- **retention** — why they came back or didn't, what they remember
- **other**
